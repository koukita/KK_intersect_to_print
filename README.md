# KK_intersect_to_print

地図上でクリックした地点と交差するポリゴンレイヤを検索し、属性をポイントに保存して、QGISのレイアウトからPDFを作成するプラグインです。

たとえば、クリック地点の土地利用、森林区域、農用地区域、自治体などの情報をまとめて確認・印刷できます。

## 対応環境

- QGIS 3.44～4.x
- 検索対象はベクタのポリゴンレイヤです。

## インストール

1. [インストール用ZIP](./インストール用ZIP/KK_intersect_to_print_0.9.5.zip)をダウンロードします。
2. QGISの **プラグイン > プラグインの管理とインストール** を開きます。
3. **ZIPからインストール** を選び、ダウンロードしたZIPを指定します。
4. プラグイン一覧で **KK_intersect_to_print** を有効にします。

## 起動方法

QGISの **プラグイン > KK_intersect_to_print** を選ぶか、専用ツールバーのプラグインアイコンをクリックします。操作パネルはQGIS画面の右側に表示されます。

## パネルのボタンと項目

| ボタン・項目 | 説明 |
| --- | --- |
| **ポイントレイヤ** | 取得した属性を書き込むポイントレイヤを選びます。ポイントジオメトリのベクタレイヤが対象です。 |
| **ポイントレイヤ新規作成** | 「交差ポイント」という一時ポイントレイヤを作成します。同名のポイントレイヤがすでにある場合はそれを選択します。一時レイヤはプロジェクトを閉じると失われるため、必要に応じて保存してください。 |
| **属性を取得するポリゴンレイヤ** | クリック位置で検索するポリゴンレイヤの一覧です。チェックしたレイヤだけを検索します。リストの順序はレイヤパネルに従います。 |
| **レイヤリスト更新** | 現在のプロジェクトからポリゴンレイヤを再取得します。可能な限り既存のチェック状態を維持します。 |
| **全てのチェックを外す** | 検索対象のチェックをすべて外します。 |
| **全てにチェックする** | リスト内のポリゴンレイヤをすべて検索対象にします。レイヤ数が多い場合、処理に時間がかかることがあります。 |
| **表示レイヤにチェックする** | レイヤパネル上で表示状態になっているポリゴンレイヤだけを検索対象にします。 |
| **設定読み込み** | 現在のQGISプロジェクト用に保存したポイントレイヤ、検索対象、レイアウトの設定を読み込みます。 |
| **設定保存** | 現在の選択内容を設定ファイルに保存します。プロジェクトを先に保存してください。 |
| **ポイント追加** | クリック待ちの状態にします。地図上をクリックすると、クリック地点にポイントを作成し、交差する検索対象レイヤの属性を保存します。作成後、ポイントの属性フォームを開きます。 |
| **プリント（PDF保存）** | 選択中のレイアウトをPDFに出力します。保存先を指定できます。 |
| **レイアウト** | PDF出力に使用するプロジェクト内の印刷レイアウトを選びます。 |

## 基本的な使い方

1. QGISプロジェクトと、検索したいポリゴンレイヤを開きます。
2. パネルの **ポイントレイヤ新規作成** をクリックするか、既存のポイントレイヤを選びます。
3. **属性を取得するポリゴンレイヤ** で検索対象にチェックを付けます。レイヤ数が多い場合は、必要なものだけを選ぶと処理時間を短縮できます。
4. 必要なら **設定保存** をクリックして、選択内容を保存します。
5. **ポイント追加** をクリックし、地図上の調べたい場所をクリックします。
6. 表示された属性フォームで取得結果を確認します。
7. 印刷する場合は、使用する **レイアウト** を選んで **プリント（PDF保存）** をクリックし、PDFの保存先を指定します。

### 属性の記録方法

- 交差したレイヤの属性は、`レイヤ名:フィールド名` というフィールド名でポイントに保存されます。
- クリック地点が同じレイヤ内の複数地物と交差した場合、その属性値はセミコロン区切りでまとめられます。
- 交差する地物がない場合や値が空の場合、該当する属性値は空になります。
- クリックするたびに既存のポイントは削除され、最新の地点と検索結果に置き換わります。ポイントがすでに2つ以上あるレイヤでは、誤消去防止のためポイント追加を中止します。

## レイアウトとPDF出力

レイアウトはあらかじめQGISで作成してください。

1. レイアウトの **地図帳** を有効にし、カバレッジレイヤにポイントレイヤを指定します。
2. 地図アイテムで **地図帳による制御** を有効にし、縮尺などを調整します。
3. 属性をレイアウト上に表示するには、ラベルの動的テキストで地図帳地物のフィールドを指定します。
4. プラグインの **レイアウト** から対象のレイアウトを選んでPDFを出力します。

地図帳が有効なレイアウトでは、地図帳の**先頭の地物1件**をPDFに出力します。地図帳が無効なレイアウトでは、レイアウト全体を出力します。

## 設定ファイル

設定は、QGISプロジェクトと同じフォルダーに次の名前で保存されます。

```text
point_setting_<プロジェクトファイル名>.json
```

ポイントレイヤ、検索レイヤのチェック状態、レイアウト名が保存されます。プロジェクトをまだ保存していない場合は、設定の保存・読み込みはできません。
